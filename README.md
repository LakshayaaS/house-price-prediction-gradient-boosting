# House Price Prediction using Gradient Boosting

Predicts house prices from features like area, bedrooms, bathrooms and amenities, using Gradient Boosting (Python, scikit-learn) on `Housing.csv` (545 houses).

**Result:** R² 0.67 on unseen test data (up from 0.55 with Linear Regression).

**Run:** keep `Housing.csv` next to the notebook, then run all cells in `House_Price_Prediction_ML.ipynb`.
